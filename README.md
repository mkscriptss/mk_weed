# MK Weed

Complete weed growing system: supply shops, seed farms, a travelling seed dealer, a hidden weed buyer, grid planting with server-side growth, status cards, processing tables, joints, levels, private labs with workers and raids, live admin editor (ESX / QBCore / Qbox)

**Latest version:** `1.0.2` · [Changelog](CHANGELOG.md) · [Releases](https://github.com/mkscriptss/mk_weed/releases)

## Where to get it

MK Weed is a paid FiveM resource by **MK Scripts**, delivered through the Cfx.re Asset Escrow.
Buyers download every update from [portal.cfx.re](https://portal.cfx.re) → Granted Assets.

## Update check

This repository holds the release history only – no source code. When the resource starts, the server console
tells you if a newer version is published here (turn it off with `set mk_versioncheck false` in server.cfg):

```
[mk_weed] update available: v1.0.0 -> v1.0.1 https://github.com/mkscriptss/mk_weed/releases/tag/v1.0.1
```
